# HealthForward — Healthcare Single-Page Website

A responsive, single-page educational website about patient care, clinical research, healthcare data, and responsible AI, built for an introductory HTML/CSS assignment.

## Files
- `index.html` — semantic HTML5 structure and accessible page content
- `styles.css` — external stylesheet with responsive layouts and visual design

## View locally
Download this repository and double-click `index.html` to open it in your browser. No installation or build tools are required.

## Assignment requirements
- Semantic HTML: `header`, `nav`, `main`, `section`, `article`, and `footer`
- External stylesheet linked from HTML
- Heading hierarchy, descriptive navigation, accessible skip link and illustration description
- Responsive layout using CSS Grid, Flexbox, and media queries
- Version control ready for Git and GitHub

## Validation
Check `index.html` at https://validator.w3.org/ and `styles.css` at https://jigsaw.w3.org/css-validator/ after uploading. Test the page on desktop and mobile widths. These online validators have not been run as part of this package.

## GitHub upload
Create a public repository named `healthcare-web-project`, add these three files at the repository root, and commit them. Submit the public repository URL for peer review. Optionally enable GitHub Pages via Settings → Pages → Deploy from a branch (`main`, `/root`) to publish the site.

## Note
This is a general educational site, not medical advice.
